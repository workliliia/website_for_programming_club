# Programming Club Society - Website Documentation

## Overview
The **Programming Club Society** website is designed to promote the club, provide information about its goals and activities, and facilitate communication with members and potential members. It also offers a platform for visitors to get in touch with the club, access social media, and find details about the club's location.

## Website Structure
The website consists of the following sections:

### Header Section
- Displays the logo and navigation links.
- A button to access the contact page.

### Navigation Bar
- Contains links to key sections: Home, Committee, Contact, Pricing, Download.
- Utilizes **Bootstrap** for responsive design and collapsible functionality on smaller screens.

### Purpose Section
- Describes the club's mission and its goal to support learning and development in programming.
- Includes an image and descriptive text explaining the club's values of equality and support.

### Location Section
- Displays the location of the club with a map embedded using **Google Maps**.
- The address is listed, and the map is embedded for easy navigation.

### Footer Section
- Contains social media links to Instagram and WhatsApp.
- Provides a link to the Terms & Conditions page.
- Displays the copyright statement, indicating the designer's name.

### Contact Section
- Allows users to send inquiries via a contact form.
- Users can input their name, email, and message.

## Key Features

### Responsive Design
The site uses a combination of custom CSS and the **Bootstrap** framework to ensure the website is fully responsive. This allows the website to adjust its layout on various screen sizes, including mobile devices.

### Typography
The site uses the **Montserrat** and **Lora** font families from Google Fonts for readability and a clean aesthetic.

### Social Media Links
The footer includes social media icons (Instagram and WhatsApp), linking to the respective platforms.

### Interactive Map
The location of the club is shown via an interactive **Google Map** embedded within the website.

### Contact Form
The contact form is simple and consists of a name, email, and message field, allowing visitors to reach out to the club directly.

## Styles & CSS

The website’s design is driven by custom CSS along with external libraries like **Bootstrap** and **Font Awesome**.

### Color Scheme
- Primary color: `#ffcd42`
- Secondary color: `#ffd35c`
- Background colors: `#ffffff` (primary), `#253237` (dark), `#7f4dc2` (map background)

### Fonts
- **Montserrat** is used for the navigation and button text to give a modern, bold appearance.
- **Lora** is used for the main text for readability and elegance.

### Layout and Spacing
- Margins and paddings are controlled through CSS variables, ensuring consistency throughout the site.
- The navigation bar has a fixed position and a dark background with contrasting text to ensure easy navigation.
- The purpose section and contact form are padded and spaced to provide a user-friendly interface.

## JavaScript & Interactivity

The website uses JavaScript features like:
- Collapsible navigation bar for mobile view (provided by **Bootstrap**).
- Hover effects on buttons and links.
- Dynamic map location integration.

## Accessibility

- The website includes alt text for images and icons for better accessibility.
- Buttons and interactive elements have visual states like hover effects to ensure ease of use.

## External Libraries Used
- **Bootstrap 4**: Used for responsive layout and collapsible navbar.
- **Font Awesome**: Used for social media icons.
- **Google Fonts**: Fonts - **Montserrat** and **Lora** for text styling.

## Conclusion
The **Programming Club Society** website is a modern and user-friendly platform designed to enhance the club's online presence. It integrates clear navigation, essential information, and interactive features to make it easy for members and visitors to engage with the club. The responsive design ensures that it is accessible across different devices, providing a seamless experience for all users.
